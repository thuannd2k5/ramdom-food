# Random Food App 🍲🎲

Ứng dụng gợi ý món ăn ngẫu nhiên và tìm kiếm quán ăn xung quanh thông qua GPS dành cho dân văn phòng và sinh viên.

## Cấu trúc dự án
- `apps/backend`: Backend NestJS + Mongoose (MongoDB Atlas) + Swagger + Jest.
- `apps/mobile`: Frontend React Native + Expo SDK + Expo Router + TanStack Query.
- `docs/`: Tài liệu đặc tả yêu cầu, kiến trúc hệ thống, schema database và API.
